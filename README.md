## 🚀 Featured Project — Fixiwala

**Fixiwala** is an Android application under development that aims to connect customers with nearby service professionals.

### Key Features

* 🔐 Phone number authentication
* 🛠️ Local service discovery and booking
* 🏠 Rental services
* 💼 Job listings and applications
* 🛒 Product marketplace
* 📍 Location-based discovery
* 🗺️ Google Maps integration
* 💬 Real-time messaging — planned/in development
* 🔔 Push notifications
* 💳 Online payment integration

**Mission:** Make local services easier to discover and book.
